🖥️ Section 1 · 我的开发环境 — "一个人 + 一台电脑 + AI"
🖥️
硬件：云服务器 (Debian Linux)
不是顶配游戏电脑，就是一台普通的云端 Linux 服务器。浏览器跑在你的电脑里，代码和 AI 在云端运行。
🤖
AI 助手：Claude Code v2.1.104
一个能读代码、写代码、运行命令、搜索网络、管理文件的 AI。想象成一个从不睡觉、反应极快的初级开发员。
💬
编程语言：3种
HTML + CSS + JavaScript — 负责你看到的 Dashboard 界面。
Python — 负责 AI 智库的后端逻辑。
💰 使用工具：全部免费开源，零付费软件
🗺️
Leaflet
开源地图库。类似 Google Maps，但完全免费、可定制。所有哥伦比亚地图都用它画的。
📊
ECharts
图表库。柱状图、饼图、趋势线全靠它。百度开源，全球主流数据可视化工具之一。
🔀
Git / GitHub
版本控制系统。每次改动都有记录，像"整个项目的撤销历史"。共 114 次提交，每次都有说明。
🌐
GitHub Pages
免费网站托管。把 HTML 文件放上去，全世界都能访问。无需服务器，无需域名费用。
🤖
Playwright
自动化浏览器测试工具。一个机器人自动打开网站、点按钮、检查有没有 Bug，代替人工手动测试。
🐍
FastAPI
Python 后端框架。AI 智库用它来接收请求、处理逻辑、返回分析结果。
📝
VS Code / Terminal
编辑器和命令行工具。AI 在终端里直接运行代码，不需要手动点按钮。
🎨
零付费设计工具

Phase 10 · May 22–23
分屏联动大战 Split-View Sync Battle
📅 May 22–23 🐛 5 Rounds of Debugging
  • Root Cause 1: window.map was not a Leaflet object — let map inside a function scope never assigned to window
  • Root Cause 2: map.off('move') removed ALL move handlers including Leaflet internals — broke pan/zoom entirely
  • Root Cause 3: Heatmap data contained 5 NULL coordinate points from Box-Muller extreme values
  • Root Cause 4: const MR_HEATMAP declared after first usage — Temporal Dead Zone error
  • Built Playwright automated browser testing to validate split-view behavior end-to-end
  • Final fix: named handler references + safe event unbinding + NaN coordinate filtering
5 debugging rounds. Each fix revealed the next deeper bug. The TDZ bug was the sneakiest — no error thrown, just silent failure at runtime.

Key Learnings

14 phases. 1 rollback. 5 debugging rounds. Here's what actually mattered.

🎯
Start With the User's Question
A CMO doesn't want raw network metrics — they want business outcomes. Every feature decision was filtered through "does this answer a question the CMO would actually ask on Monday morning?"
🔄
Incremental Over Big Bang
Phase 6 was the proof. Changing the entire visual system in one commit — fonts, spacing, colors, layout — created chaos. Every subsequent redesign was done in small, reviewable increments with a checkpoint after each.
🐛
Named Event Handlers Are Non-Negotiable
Calling map.off('move') with anonymous functions removes ALL handlers of that type — including internal Leaflet ones. Always store references to handlers and use map.off('move', namedHandler) for safe unbinding.
🌍
Real Data Changes Perception
Switching from circle markers to real GeoJSON boundaries, and from synthetic site grids to Gaussian + corridor placement, transformed the dashboard from "demo" to "production-ready" in users' minds — even with identical underlying data.
🔍
QA Must Scan Code, Not Just HTML
55 untranslated strings were hiding inside JavaScript template literals. HTML-only QA tools missed them entirely. i18n validation needs to parse JS string contexts too — always use JS-aware regex patterns.
🎨
Color Carries Semantics
The RSRP heatmap color change from blue-green to red-yellow-green took 30 minutes. The credibility gain with domain experts was instant — they immediately recognized the industry-standard signal quality convention.
⚡
Canvas Over DOM at Scale
146,000 DOM elements for the CTO grid would crash any browser. Canvas rendering with direct pixel manipulation made it smooth. The lesson: choose the rendering primitive that matches your data density, not your coding convenience.
🧪
Automate What You'll Recheck
The split-view sync broke four times during development. Building Playwright E2E tests after the third break meant the fourth regression was caught in CI, not in a demo. Automation investment pays back on the second failure.

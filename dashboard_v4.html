CMO Dashboard 使用说明

📊 框架概述

本大屏整合六层数据源（公参、无线KPI、网络KPI、探针DPI、Ookla测速、IMSI流失），从用户、体验、业务、终端、潜力五个维度为 CMO 提供一站式决策支撑。

🗺️ 界面布局

左上 — 用户趋势
在网用户数 + 52周趋势图 + 区域增减警报
右上 — 网络指标
下拉选择速率/时延/覆盖，趋势图 + 区域排名
左下 — 终端分布
高价值终端柱状图，点击查看大区分布
右中 — 竞对分析
Tigo vs Claro 速率/覆盖对比 + 周趋势
右下 — 流失分布
月度流失 + 城市分布 + 周趋势柱状图
底部 — APP 体验
YouTube/Netflix/TikTok/流量 饼图 + 关键指标

🗂️ 地图图层（9 个）

网络指标 按选中指标（速率/时延/覆盖）着色区域，联动右上下拉
vs Claro 与 Claro 的差距对比，联动右上选中指标
用户增长率 5 档颜色（深绿→深红），按区域增减着色
新增用户 各区域新增用户数，蓝色深浅表示多少
流失分布 流失率高的区域标红，低的标绿
视频体验 YouTube HD 占比，按区域着色
覆盖分析 RSRP 分布图 + Tigo/Claro 热力图 + 分屏对比
终端分布 选择终端型号，热力图显示用户分布
分屏 左右分屏：终端热力 vs 网络覆盖，同步联动

🖱️ 交互操作

• 点击区域多边形 → 下钻到城市级，显示站点标记（红/黄/绿告警）
• 点击底部 APP 卡片 → 弹出详情面板（分辨率分布 + 城市对比 + 趋势图）
• 点击终端柱状图 → 展开该终端在各大区的分布
• 点击城市名/区域名 → 下钻到诊断页（六维归因 + 建议行动）
• 右上下拉菜单 → 切换指标，地图和图例联动变化
• EN / 中文 按钮 → 中英文界面切换

🔗 CMO 决策链

发现 → 用户趋势 + 区域警报：哪里在增长、哪里在流失
定位 → 体验 + 覆盖 + 竞对：为什么流失（网络差 or 竞对强）
量化 → 流失 + 终端：损失多少用户、多少收入
行动 → 下钻诊断：哪些站点需要扩容 / 补盲
验证 → 持续监控：扩容后指标是否改善

📦 数据源

本 Demo 使用模拟数据（~5,200 站点，30+ 城市，高斯分布 + 公路走廊）。
生产环境接入：公参 OMC / 无线话统 / 核心网 / DPI 探针 / Ookla Speedtest Intelligence / IMSI 信令。
